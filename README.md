1. Project Overview
This project focuses on cleaning and preparing a raw dataset using Microsoft Excel. The objective is to improve data quality, accuracy, and consistency by identifying missing values, checking for duplicates, and correcting inconsistencies in the dataset.
2. Project Objectives
•	Identify missing or null values.
•	Detect and remove duplicate records.
•	Standardise date formats.
•	Ensure consistency in numerical entries.
•	Correct text inconsistencies.
•	Improve overall data quality and reliability.
3. Tools Used
Microsoft Excel
Techniques and functions applied include:
•	Data filtering and sorting.
•	Excel formulas.
•	TRIM function.
•	Date formatting.
•	Data validation.
•	Data consistency checks.
4. Data Cleaning Process
The following areas were addressed during the project:
Date Formatting: Standardised date entries to the required yyyy-mm-dd format.
Text Cleaning: Reviewed text entries for inconsistent capitalisation and unnecessary spaces.
Numerical Consistency: Checked numerical entries for formatting and consistency.
Missing Values: Identified and reviewed missing entries, including transaction coupon-code fields. No N/A placeholder was inserted.
Duplicate Records: Reviewed transaction records to identify duplicate IDs.
5. Verification
Additional checks were performed to assess the quality of the cleaned dataset.
The verification process focused on:
•	Duplicate transaction IDs.
•	Date format consistency.
•	Numerical accuracy.
•	Text consistency.
•	Missing values.

•	Data validation and verification.
•	Identifying inconsistencies.
•	Maintaining data integrity.
